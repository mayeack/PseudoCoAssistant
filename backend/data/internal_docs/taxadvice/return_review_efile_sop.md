# Return Review & E-File SOP

Scope: this standard operating procedure covers every individual and small-business return the firm prepares, from the preparer's first draft to the IRS e-file acknowledgment. No return is transmitted without completing every step below.

Two-person review: a second preparer who did not draft the return reviews it against the source documents before it goes to the client. The reviewer ticks the review checklist (income tie-out, dependents, credits, estimated payments applied, bank details for direct deposit) and signs the review log.

Client signature: the client signs Form 8879, the e-file signature authorization, before transmission. A return is never e-filed on verbal approval; an unsigned 8879 holds the return in the queue.

E-file rejections: the preparer checks the e-file queue every morning in filing season. A rejected return (for example a dependent already claimed, or an AGI mismatch on the prior-year return) is corrected and retransmitted within two business days, and the client is told the reason in plain language.

Extensions: any return missing documents by April 1 gets Form 4868 filed by the preparer, with an estimated payment calculation sent to the client. An extension extends the time to file, not the time to pay.

Retention: the signed 8879, the review checklist and the source documents are kept for three years after filing in the document management system.
