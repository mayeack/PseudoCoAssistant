# Network Outage Escalation SOP

Scope: this standard operating procedure covers how care agents and the virtual assistant handle a customer report of no service, dropped calls or no internet, and when a reported problem becomes a declared network outage.

First check: the agent looks up the customer's service address on the outage map. If an area outage is already open, the agent gives the customer the network operations center's estimated restoration time, never a guess, and offers outage text alerts.

Declaring an outage: when 25 or more tickets arrive from one network node within 30 minutes, the shift lead declares a Severity 2 outage and opens a bridge with the network operations center. Any outage affecting 911 voice calls is declared Severity 1 at once.

Customer troubleshooting: with no open outage, the agent walks the customer through restarting the modem or router, checking cables and running the line test before booking a technician visit.

Credits: customers affected by an outage lasting more than 24 hours receive an automatic prorated service credit on the next bill. Agents do not promise any credit beyond the automatic outage credit.

Follow-up: when the outage is closed, customers who opted in get a restoration text, and any ticket still failing the line test is reopened for a technician.
